Shipping a desktop app with Wails3

#go #wails #react
1Wails3 lets you ship a Go backend and a web frontend as one native binary.
2It uses the OS webview, so there's no bundled Chromium.
3
4## Project setup
5
6```bash
7wails3 init -n relay -t react-ts
8cd relay && wails3 dev
9```

13## Calling Go from React
14
15Every exported method on a **bound service** gets a typed JS binding:
16
17```go
18func (p *PostService) Save(post Post) error {
19 return p.store.Write(post.Slug, post.Markdown())
