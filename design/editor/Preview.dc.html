Shipping a desktop app with Wails3

#go#wails#react

Wails3 lets you ship a Go backend and a web frontend as one native binary. It uses the OS webview, so there's no bundled Chromium.

Project setup

wails3 init -n relay -t react-ts
cd relay && wails3 dev

Calling Go from React

Every exported method on a bound service gets a typed JS binding:

func (p *PostService) Save(post Post) error {
    return p.store.Write(post.Slug, post.Markdown())
}

The full API reference lives in the Wails docs.
