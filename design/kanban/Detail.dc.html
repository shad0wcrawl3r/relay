Plane → Grafana annotations bridge

State
Priority

Created

Description

When a WORK item moves to In Progress or Done, drop an annotation on the ingest dashboards so parser changes line up with log-volume shifts.

Claude Codeagent2h ago

Expansion

A small Go service: poll Plane for WORK state changes, post them to Grafana's annotations API, tag each by module.

Case for

Sits on the Grafana/Alloy stack you already run; parser changes become visible next to EPS graphs.

Case against

Polling Plane Cloud is wasteful and webhooks need a public endpoint. Annotations get noisy fast.

Verdict · Prototype first

First 3 steps

  1. Pick the 2–3 state transitions worth annotating.
  2. Spike: poll updated items, post annotations.
  3. Run it a week on one dashboard, then decide.
